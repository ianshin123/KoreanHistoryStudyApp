# 한국사 시험대비

천재교육 『고등 한국사 2』(정요근 외) **교과서 8~85쪽**을 위한 개인 학습용 웹앱.
빌드 단계가 없어 GitHub Pages가 파일을 그대로 서빙하며, 홈 화면에 추가하면 앱처럼 쓸 수 있다(PWA·오프라인).

**소단원 21개 · 문항 219개 · 연표 86항목 · 그림 226장 — 시험 범위 전체 수록.**

## 쓰는 법

목차에서 단원을 누르면 그 안에서 바로 학습하고 문제를 푼다. 화면은 **목차**와 **연표** 둘뿐이다.

```
목차 ──▶ 소단원 ──▶ [ 핵심 정리 / 자료 / 문제 ]
  └──▶ 중단원 「문제」 버튼 ──▶ 중단원 범위 문제
  └──▶ 전범위 문제풀기
연표 ──▶ 1905~1950년을 통으로, 시간순 세로 배치
```

- **핵심 정리** — 교과서를 그대로 옮기지 않고 뼈대만. 한 줄 요약, 계층 불릿,
  흐름도(A→B→C), 대조표(표면↔실상, 좌익↔우익), 용어.
- **자료** — 사료 원문과 그림·도표를 모아 두어 직접 읽는다. 쪽별 **원본 보기**로 교과서 지면을 그대로 확대할 수 있다.
- **문제** — 소단원·중단원·전범위 어느 단위로든 바로 풀 수 있다.

진도나 학습 완료 표시는 없다. 저장하는 것이 없으니 어긋날 것도 없다.

## 문항

실제 모의고사처럼 **자료 제시형**이 중심이다.

| format | 내용 |
|---|---|
| `source-pos` / `source-neg` | 사료 제시 후 옳은 / 옳지 않은 것 고르기 |
| `compare` | (가)·(나) 두 자료 비교 |
| `graph` · `image-id` · `image-ctx` | 그래프·사진 제시형 |
| `order` · `timeline` | 순서 배열, 연표에서 시기 찾기 |
| `cloze` · `short` · `ox` | 빈칸·단답·O/X |
| `essay` | 서술형 — 모범답안 + 배점별 채점 기준 자가 채점 |

`negative: true` 문항은 **“옳지 <u>않은</u>”**을 붉게 강조한다.
부정 발문을 놓쳐서 틀리는 건 실력이 아니라 화면 탓이다.

## 구조

```
index.html
app/          main(라우터) data(적재) ui(공통) home section quiz timeline
styles/main.css          한지색 바탕·먹색 글·단청 적청, 제목은 명조
data/toc.json            단원 트리 (ready·문항 수는 자동 반영)
data/figures.json        그림 226장의 목록과 캡션
data/sections/*.json     소단원 21개 — 핵심 정리·용어·연표·사료·그림
data/questions/*.json    문항 219개
assets/img/              교과서 그림 크롭 (226장)
assets/page/             펼침면 원본 78장 (「원본 보기」용)
tools/                   extract.py · crop.py · sync_toc.py
```

## 도구

```bash
pip install pymupdf pillow

python3 tools/extract.py 5 6                  # PDF 5~6쪽(교과서 12~15쪽) 텍스트를 역할별로 추출
python3 tools/crop.py pages 3 41              # 펼침면 원본 렌더
python3 tools/crop.py figures 3 41 --vectors  # 그림 크롭 (벡터 도표 포함, 캡션 자동 연결)
python3 tools/sync_toc.py                     # 목차의 준비 상태·문항 수 갱신, 없는 그림 참조 제거
```

PDF 1장 = 교과서 펼침 2쪽이며, PDF `n`쪽의 왼쪽이 교과서 `2n+2`쪽이다.
텍스트 레이어가 살아 있어 OCR이 필요 없고, 글꼴·크기·색으로 본문/소제목/사료/캡션을 가려낸다.

```bash
python3 -m http.server 8801   # http://localhost:8801
```

## 저작권

교과서 본문과 이미지의 저작권은 원저작자(천재교육)에게 있다.
개인 학습 목적으로만 쓰며, `robots.txt`와 `noindex`로 검색엔진 색인을 막아 두었다.
